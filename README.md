# Kindergarten Marketing v2

Лендинг из шести секций. Текст перенесён дословно из нового описания оффера.

Готовые HTML, CSS, JavaScript, шрифты и изображения находятся в корне и в docs. Обе папки подходят для публикации через GitHub Pages.

Адрес: https://Slonik01.github.io/kindergarten-marketing-v2/

## Сборка

Node.js 22 или новее. После установки зависимостей выполните npm run build. Сборка обновляет статические файлы и в корне, и в docs.

## Форма

GitHub Pages содержит демонстрационную форму: поля проверяются локально, данные никуда не отправляются. Серверные ключи и обработчик заявок сюда не включены.
